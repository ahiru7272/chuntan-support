# ちゅん単（ChunTan）公式サポート

**ちゅん単**は、25,000語（Level 1〜25）の語彙データベースをもとに、ベイズ推定による語彙力診断と洋書・映画・ドラマの多読事前学習ができる iOS 向け英単語アプリです。

* **App Store**: [ちゅん単をダウンロード](https://www.google.com/search?q=https://apps.apple.com/jp/app/id6831177503)
* **公式 X（お問い合わせ・最新情報）**: [@ahiru_lab](https://x.com/ahiru_lab)
* **プライバシーポリシー**: [privacy.html](https://www.google.com/search?q=https://ahiru7272.github.io/chuntan-support/privacy.html)

## 主な機能一覧

| タブ / 機能 | 内容 |
| :--- | :--- |
| **クイズ学習** | 優先度学習・語彙力診断・復習モード・自動音声再生・学習履歴からのマイグループ一括追加 |
| **スキャン・グループ管理** | カメラ撮影／写真選択／囲み枠スキャンによる英文OCR抽出、マイグループ作成・共有（インポート／エクスポート）、例文生成＆穴埋め4択クイズ |
| **洋書・作品別 DB（v1.2）** | カタログ同期による作品データの取得、現在の推定語彙力に基づくカバー率診断（95%・98%多読ライン目安）、Level 1〜25 分布表示、未知語リストからのグループ登録 |
| **翻訳・構文 (Beta)** | 英文の構文・読解サポート機能 |
| **連続音声リスニング** | 「英語 → 日本語 → 英語」の耳だけ復習、画面下部ミニプレイヤーおよびロック画面での再生コントロール対応 |
| **ダッシュボード** | 推定語彙数の推移、資格目安（英検・TOEIC・TOEFL・ネイティブ対比）、日別学習記録・レベル別修得率の可視化 |
| **25,000語図鑑・設定** | Level 1〜25 全収録語彙の検索・閲覧、音声・通知・カタログ配信元URLなどの各種設定 |

## 基本的な使い方（クイックスタート）

1. **現在の語彙力を測る**
   「クイズ学習」タブから **語彙力診断** を実行し、現在の推定語彙数とレベルを把握します。
2. **読みたい・観たい作品のカバー率を調べる**
   「スキャン・グループ」タブ → **洋書・作品別 DB** を開き、**「GitHubから最新カタログ取得」** をタップします。気になる作品を選ぶと、現在の語彙力でのカバー率や Level 1〜25 の語彙分布、95%／98%到達に必要な未知語リストを確認できます。
3. **未知語をグループにまとめて集中攻略する**
   作品別単語帳やカメラ・囲み枠スキャンで抽出した未知語をマイグループに追加し、「クイズ学習」や「連続音声リスニング」で一気に定着させます。

## よくある質問（FAQ）

### 作品カタログが更新されない／最新作品が表示されない
「スキャン・グループ」→「洋書・作品別 DB」内の **「GitHubから最新カタログ取得」** ボタンを再度タップしてください。通信環境が不安定な場合は、Wi-Fi 接続時にお試しください。

### 英語・日本語の音声が再生されない
* iPhone 本体の消音スイッチ（マナーモード）がオンになっていないか確認してください。
* メディア音量が下がっていないか確認してください。
* 「設定」タブ内の音声関連の設定（読み上げ速度・音声種別など）を見直してください。

### カメラや写真ライブラリで単語スキャンができない
iPhone の **「設定」アプリ →「ちゅん単」** から、カメラおよび写真へのアクセス権限が許可されているか確認してください。
